# ระบบแจ้งซ่อมไฟฟ้าสาธารณะ — อบต.แม่ก๊า (MVP)

สแกน QR ที่เสา → ระบบรู้ทันทีว่าเป็นเสาต้นไหน (ไม่ต้องกรอกเลขเสาเอง) → เก็บพิกัด Lat/Long →
ช่างไฟดูงานทั้งหมดบนแดชบอร์ด + แผนที่ + อัปเดตสถานะแบบ incident

**ขอบเขต:** เสาไฟ ~1,300 ต้น / 14 หมู่ · รหัสเสา = `หมู่/ต้นที่` เช่น `1/14` = หมู่ 1 ต้นที่ 14

## องค์ประกอบ
| ไฟล์ | หน้าที่ |
|---|---|
| `apps_script/Code.gs` | เซิร์ฟเวอร์ (รับแจ้ง / กันแจ้งมั่ว / อ่าน-อัปเดตงาน / แจ้งเตือนอีเมล) |
| `apps_script/appsscript.json` | manifest — ตั้ง timezone Asia/Bangkok |
| `apps_script/report.html` | หน้าชาวบ้านแจ้งซ่อม (เปิดจาก QR) |
| `apps_script/admin.html` | แดชบอร์ดช่างไฟ + แผนที่ (Leaflet ฟรี) + กรองตามหมู่/สถานะ + บล็อกเบอร์ |
| `apps_script/poles_template.csv` | เทมเพลตข้อมูลเสา + พิกัด |
| `docs/qr_generator.html` | สร้าง QR 1,300 ต้นแบบชุดตามหมู่ + ลายเซ็นกันปลอม + พิมพ์/CSV |

## ระบบป้องกันการแจ้งมั่ว (ในตัว)
1. เสาต้นเดียวมีงานค้าง → ไม่รับซ้ำ บอกเลขที่เดิม
2. เบอร์เดียวแจ้งได้ 3 ครั้ง/วัน (`MAX_REPORTS_PER_PHONE_PER_DAY`)
3. บัญชีดำเบอร์โทร (ชีต `Blocklist`) — ช่างกดบล็อกจากแดชบอร์ด
4. Honeypot + ส่งเร็วกว่า 3 วิ = บอท
5. QR มีลายเซ็น `&k=` (เปิดใช้เมื่อตั้ง `QR_SECRET`) — พิมพ์ URL มั่วเสาอื่นไม่ได้
6. สถานะ "แจ้งเท็จ" + ป้ายเตือนเบอร์ที่เคยแจ้งเท็จบนแดชบอร์ด

## ขั้นตอนติดตั้ง (ครั้งเดียว ~30 นาที)

### 1) สร้าง Google Sheet
- สร้าง Google Sheet ใหม่ด้วย **บัญชี Google ของ อบต.** (ไม่ใช่ส่วนตัว)

### 2) ติดตั้ง Apps Script
1. ใน Sheet: **ส่วนขยาย (Extensions) → Apps Script**
2. วางเนื้อหา `Code.gs` ลงไฟล์ `Code.gs`
3. กด **+** เพิ่มไฟล์ HTML ชื่อ `report` และ `admin` (ไม่ต้องมี .html) → วางเนื้อหาจากไฟล์
4. **⚙️ Project Settings → Script Properties** เพิ่ม:
   - `ADMIN_TOKEN` = รหัสเข้าแดชบอร์ดช่าง (บังคับ)
   - `NOTIFY_EMAIL` = อีเมลช่างที่จะรับแจ้งงานใหม่ (ไม่บังคับ)
   - `QR_SECRET` = รหัสลับลายเซ็น QR (ไม่บังคับ แต่แนะนำ)
5. **Project Settings → ติ๊ก "Show appsscript.json"** → วางเนื้อหา `appsscript.json` (ตั้ง timezone ไทย)
6. เลือกฟังก์ชัน **`setupSheets`** → กด **Run** → สร้างชีต `Poles` `Reports` `Blocklist` พร้อมล็อกคอลัมน์เลขเสาเป็นข้อความ

### 3) กรอกข้อมูลเสา
- ชีต `Poles`: วางข้อมูลตาม `poles_template.csv` (`pole_id, zone, address, lat, lng, note`)
- ⚠️ **ต้องรัน `setupSheets` ก่อนวาง** ไม่งั้น `1/14` จะกลายเป็นวันที่ 14 ม.ค.
- พิกัด: ยืนที่เสา เปิด Google Maps กดค้าง → คัดลอกเลข 2 ตัว
- รัน **`checkPoles`** แล้วดู Logs เพื่อหาเลขซ้ำ/ไม่มีพิกัด/รูปแบบผิด

### 4) Deploy เป็น Web App
- **Deploy → New deployment → Web app** · Execute as = **Me** · Who has access = **Anyone**
- คัดลอก **Web app URL** (ลงท้าย `/exec`)

### 5) สร้าง QR รายเสา
- เปิด `docs/qr_generator.html` → วาง URL + QR_SECRET → ใส่จำนวนต้นต่อหมู่ → สร้าง → พิมพ์ทีละหมู่

### 6) ใช้งาน
- **ชาวบ้าน:** สแกน QR → เห็น "หมู่ X ต้นที่ Y" อัตโนมัติ → กรอกชื่อ/เบอร์/อาการ → ส่ง
- **ช่างไฟ:** `WebAppURL?page=admin` → ใส่รหัส → งานทั้งหมด + หมุดแผนที่ + นำทาง Google Maps + เปลี่ยนสถานะ

## หมายเหตุ
- ต้นทุน ~0 บาท (รันบน Google) · แผนที่ใช้ OpenStreetMap ไม่ต้องมี API key
- ข้อมูลผู้แจ้ง = PII — ห้าม export ขึ้น repo สาธารณะ
- **แผนต่อไป:** พิจารณาย้ายไป Vercel/Cloudflare + Supabase — ดูบันทึกใน `private/` (ไม่ขึ้น git)
